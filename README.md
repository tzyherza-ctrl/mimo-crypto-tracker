# 🚀 MiMo Crypto Tracker

> AI-powered cryptocurrency portfolio dashboard built with Next.js 15 + Xiaomi MiMo V2.5

![Next.js](https://img.shields.io/badge/Next.js-15-black)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)
![Tailwind](https://img.shields.io/badge/Tailwind-3.4-teal)
![MiMo](https://img.shields.io/badge/Xiaomi-MiMo-orange)

## ✨ Features

- **📊 Real-time Market Dashboard** — Live prices, market cap, volume from CoinGecko
- **📈 Interactive Price Charts** — 7-day sparkline charts with Recharts
- **💼 Portfolio Tracker** — Track holdings, P&L, ROI calculations
- **🤖 MiMo AI Analyst** — Chat with Xiaomi MiMo V2.5 for market analysis
- **🌙 Dark Mode** — Sleek dark UI optimized for extended use
- **⚡ Auto-refresh** — Data updates every 30 seconds

## 🛠 Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Icons:** Lucide React
- **AI Model:** Xiaomi MiMo V2.5
- **Data:** CoinGecko API (free tier)

## 🚀 Getting Started

```bash
npm install
cp .env.example .env.local
# (Optional) Add your MiMo API key to .env.local
npm run dev
```
